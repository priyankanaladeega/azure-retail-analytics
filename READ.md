# Azure Retail Analytics Platform

An end-to-end cloud analytics project built using Azure Data Lake Storage Gen2, Azure Data Factory (ADF), Azure SQL Database, SQL-based dimensional modeling, and Power BI.

# Project Architecture

CSV Files (examples used from Kaggle for raw data)

→ Azure Data Lake Gen2 (Bronze Layer)
→ Azure Data Factory Pipelines
→ Azure SQL Staging Tables
→ Fact & Dimension Warehouse
→ Power BI Reporting Layer

## Technologies Used

- Azure Data Lake Storage Gen2
- Azure Data Factory (ADF)
- Azure SQL Database
- SQL Server / SSMS
- Power BI
- Power Query
- DAX

## Project Goals

- Build cloud-based ETL pipelines
- Implement dimensional warehouse modeling
- Automate ingestion workflows
- Create scalable reporting architecture
- Develop business-ready Power BI dashboards
